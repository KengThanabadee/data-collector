# Triage labels

| Role | GitHub label | Use |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer review is pending. |
| `needs-info` | `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | `ready-for-agent` | The ticket is specified and ready for an agent when its blockers are closed. |
| `ready-for-human` | `ready-for-human` | A human needs to drive the work. |
| `wontfix` | `wontfix` | The project declined the request. |
